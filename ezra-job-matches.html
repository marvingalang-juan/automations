Before applying

Fix the CV and set the salary ask

CV fixes, in priority order

  1. Change the address to Pampanga, or add "Relocating to Clark/Angeles, available immediately". Recruiters in Clark often filter out Metro Manila addresses.
  2. Make the name match LinkedIn (ezra-pineda) and the email, for example with "Ezra Espiritu (née Pineda)" if that applies.
  3. Move Docker, Kubernetes and Elasticsearch to a "Familiar with" line, or add one bullet showing real use. Interviewers will test anything listed.
  4. Add a Kyndryl bullet about Ansible or Bash automation, with a number (hours saved, servers patched).
  5. Start studying for RHCSA (EX200). Even "RHCSA in progress, exam Dec 2026" lifts the top three matches.
  6. Write "RHEL" consistently, and replace the references with "Available upon request".
